Panel de administrador

¿Cómo obtengo mi clave? Solo se hace una vez:
  1. Con tu sesión de GitHub abierta, toca este enlace: Crear mi clave. Ya viene con el permiso correcto marcado.
  2. En Expiration elige cuánto dura (por ejemplo 1 año).
  3. Baja y presiona el botón verde Generate token.
  4. Copia la clave (empieza con ghp_) y pégala aquí. No se la envíes a nadie.
