Panel de administrador

¿Cómo obtengo mi clave? Solo se hace una vez:
  1. Entra a GitHub → Fine-grained token.
  2. Ponle un nombre (ej. admin tienda) y una fecha de vencimiento.
  3. En Repository access elige Only select repositories y selecciona el repositorio de la tienda.
  4. En Permissions → Contents elige Read and write.
  5. Crea el token, cópialo y pégalo aquí. No lo compartas con nadie.
